- 어떤 불편을 풀고 싶은지 한 문장으로 쓰기 — 여행 날짜에 어디가 좋은지, 맛집은 어디인지 하나하나 찾아봐야 해서 번거로워요.

- 누가 쓰는지 쓰기 — 여행 날짜를 입력해서 국내 여행 리포트를 받아 보는 사용자예요.
