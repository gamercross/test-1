> 잘된 점과 아쉬운 점 돌아보기

- 잘된 점: 프롬프트 저장, 카테고리, 검색, 즐겨찾기를 하나씩 확인하며 통과했어요 · 아쉬운 점: 성공의 기준 숫자를 끝까지 정하지 못했어요

- 재료: 5단계 Ⅱ 도는지 보기 · 6단계 Ⅱ 작은 확인 · 6단계 Ⅲ 써 보기 · 7단계 Ⅲ 못 잰 것

## 왜 다섯 번

> '왜?'를 다섯 번 물어 진짜 원인 찾기

- 왜? 성공 기준을 못 정했나 → 숫자로 말하는 걸 미뤘어요 → 처음에 '아직 모름'으로 넘겼어요 → 몇 번 걸리면 성공인지 생각 안 했어요 → 진짜 까닭: 시작할 때 성공 모습을 숫자로 안 그렸어요
- 어떻게: 고름 — 플로로가 권한 것: “왜? 성공 기준을 못 정했나 → 숫자로 말하는 걸 미뤘어요 → 처음에 '아직 모름'으로 넘겼어요 → 몇 번 걸리면 성공인지 생각 안 했어요 → 진짜 까닭: 시작할 때 성공 모습을 숫자로 안 그렸어요”
- 재료: 2단계 Ⅱ 왜 · 어디까지 · 언제 성공 · 3단계 Ⅱ 숫자로 · 7단계 Ⅰ 숫자 재기 · 7단계 Ⅲ 못 잰 것

## 아찔했던 일

> 정보가 샐 뻔했던 일이나 아찔했던 일 적기

- 없었어요 — 다음엔 프롬프트에 비밀번호나 남의 정보를 적지 않도록 저장 전에 한 번 훑어볼게요
- 어떻게: 고름 — 플로로가 권한 것: “없었어요 — 다음엔 프롬프트에 비밀번호나 남의 정보를 적지 않도록 저장 전에 한 번 훑어볼게요”
- 재료: 2단계 Ⅳ 남의 정보 · 밖으로 · 6단계 Ⅳ 비밀값 검사 · 7단계 Ⅳ 아무나 못 들어오게

## 배운 것 남기기

> 배운 것을 다음에 쓸 수 있게 남기기

- 다음엔 성공 기준을 숫자로 먼저 정할게요 / 다음엔 작은 부분마다 확인 방법을 먼저 적을게요 / 다음엔 비밀값을 .env에 두고 올리기 전에 검색할게요
- 어떻게: 고름 — 플로로가 권한 것: “다음엔 성공 기준을 숫자로 먼저 정할게요 / 다음엔 작은 부분마다 확인 방법을 먼저 적을게요 / 다음엔 비밀값을 .env에 두고 올리기 전에 검색할게요”
- 재료: 3단계 Ⅱ 숫자로 · 3단계 Ⅲ 꼭 · 있으면 좋음 · 5단계 Ⅰ 끝까지 잇기 · 6단계 Ⅰ 확인 먼저

> 마친 작업을 저장소에 올려 두기

- 문서와 코드 — 커밋: 프롬프트 보관함 첫 판 완성 (.env와 저장한 프롬프트 파일 같은 비밀값은 올리지 않아요)
- 어떻게: 고름 — 플로로가 권한 것: “문서와 코드 — 커밋: 프롬프트 보관함 첫 판 완성 (.env와 저장한 프롬프트 파일 같은 비밀값은 올리지 않아요)”
