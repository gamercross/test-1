## 2. 이번 단계에서 한 일

- 잘된 점과 아쉬운 점 돌아보기 — 잘된 점: 날짜 넣기 → 지역 추천 → 맛집 찾기 → 1일 일정 리포트까지 한 흐름으로 이었고, 열쇠도 .env에 숨겼어요 · 아쉬운 점: '언제 성공'의 숫자를 못 정해서 리포트 시간과 맛집 개수를 못 재 봤어요
- '왜?'를 다섯 번 물어 진짜 원인 찾기 — 왜? 숫자를 못 재 봤어요 → 정한 숫자가 없었어요 → 2단계 '언제 성공'을 아직 모름으로 뒀어요 → 만들기 전엔 성공이 어떤 모습인지 몰랐어요 → 진짜 까닭: 만들기 전에 '성공' 모습을 숫자로 정하지 않았어요
- 정보가 샐 뻔했던 일이나 아찔했던 일 적기 — 정보가 샐 뻔한 일은 지난 결과에 없었어요. 다만 여행 날짜와 추천 지역이 AI 서비스와 지도 서비스로 나가요 — 다음엔 밖으로 나가는 것을 공개 전에 한 번 더 볼래요.
- 배운 것을 다음에 쓸 수 있게 남기기 — 다음엔 만들기 전에 '언제 성공'을 숫자로 정할래요 / 다음엔 열쇠는 .env에만 두고 올리기 전에 검사할래요 / 다음엔 작은 부분마다 확인 방법을 먼저 정할래요
- 마친 작업을 저장소에 올려 두기 — 문서와 코드 — 커밋: 여행 리포트 첫 판 정리 (비밀값은 올리지 않아요: .env 제외)
