## 5. 공부할 말

- 회고 — 끝난 뒤 잘된 점과 아쉬운 점을 돌아보는 일이에요
- 5 Whys — '왜?'를 다섯 번 물어 겉 이유 뒤의 진짜 원인을 찾는 방법이에요
- 보안 점검 — 근접 사고 — 사고는 안 났지만 날 뻔했던 아찔한 일을 적어 두는 거예요
- 체크리스트·지식 창고 — 다음에 잊지 않게 확인할 목록과, 배운 것을 모아 두는 곳이에요
- git 커밋 — 바뀐 내용을 저장소에 한 번에 묶어 남기는 거예요. 언제든 되돌아볼 수 있어요
- 검증 기록 — 잰 값 — 실제로 재 본 숫자를 그대로 적어 둔 기록이에요
- 검증 기록 — 하지 못한 것 — 아직 못 잰 것을 숨기지 않고 '아직 못 함'으로 적어 둔 기록이에요
- 보안 점검 — 공개 전 인증 확인 — 앱을 열어 두기 전에, 허락된 사람만 들어오는지 확인하는 일이에요
