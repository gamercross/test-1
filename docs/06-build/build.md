## 확인 먼저

> 확인 방법을 먼저 정하고 만들기

- 프롬프트 저장 — 하나 넣고 목록을 열면 방금 넣은 게 보여야 해요 / 카테고리 보기 — 카테고리를 고르면 그 카테고리 것만 나와야 해요 / 낱말 검색 — 낱말을 넣으면 그 낱말이 든 것만 나와야 해요 / 즐겨찾기 — 누르면 따로 모은 곳에 나와야 해요
- 어떻게: 고름 — 플로로가 권한 것: “프롬프트 저장 — 하나 넣고 목록을 열면 방금 넣은 게 보여야 해요 / 카테고리 보기 — 카테고리를 고르면 그 카테고리 것만 나와야 해요 / 낱말 검색 — 낱말을 넣으면 그 낱말이 든 것만 나와야 해요 / 즐겨찾기 — 누르면 따로 모은 곳에 나와야 해요”
- 재료: 3단계 Ⅰ 기능 문장 · 3단계 Ⅲ 꼭 · 있으면 좋음 · 5단계 Ⅱ 도는지 보기

## 작은 확인

> 작은 부분마다 확인 통과하기

- 저장: 넣은 글이 목록에 있고 빈 글은 안 들어가요 / 카테고리: 다른 카테고리 글은 안 섞여요 / 검색: 없는 낱말이면 '없어요'라고 알려 줘요 / 즐겨찾기: 다시 누르면 빠져요
- 어떻게: 고름 — 플로로가 권한 것: “저장: 넣은 글이 목록에 있고 빈 글은 안 들어가요 / 카테고리: 다른 카테고리 글은 안 섞여요 / 검색: 없는 낱말이면 '없어요'라고 알려 줘요 / 즐겨찾기: 다시 누르면 빠져요”
- 재료: 3단계 Ⅰ 기능 문장 · 5단계 Ⅱ 도는지 보기 · 5단계 Ⅲ 작게 나누기

## 써 보기

> 쓰는 사람 입장의 시나리오대로 돌려 보기

- ① 프롬프트 몇 개를 카테고리를 달아 넣어요 → ② 카테고리를 고르고, 낱말도 검색해요 → ③ 마음에 드는 것에 즐겨찾기를 눌러요 → 결과: '그때 그 프롬프트'를 메모장 없이 바로 찾아요
- 어떻게: 고름 — 플로로가 권한 것: “① 프롬프트 몇 개를 카테고리를 달아 넣어요 → ② 카테고리를 고르고, 낱말도 검색해요 → ③ 마음에 드는 것에 즐겨찾기를 눌러요 → 결과: '그때 그 프롬프트'를 메모장 없이 바로 찾아요”
- 재료: 1단계 Ⅰ 불편 · 1단계 Ⅲ 누가 · 5단계 Ⅰ 끝까지 잇기

## 비밀값 검사

> 비밀번호·키 같은 비밀값이 코드와 기록에 남지 않았는지 확인하기

- 키나 비밀번호는 .env 파일에 두고 올리지 않아요(.gitignore에 적기). 올리기 전에 코드에서 키 글자가 없는지 검색해요. 저장한 프롬프트 파일도 내 컴퓨터에만 둬요.
