## 끝까지 잇기

> 가장 단순한 흐름을 처음부터 끝까지 이어 보기

- ① 프롬프트 하나를 새로 넣어요 → ② 앱이 목록에 저장해요 → ③ 목록에서 그 프롬프트가 보여요
- 어떻게: 고름 — 플로로가 권한 것: “① 프롬프트 하나를 새로 넣어요 → ② 앱이 목록에 저장해요 → ③ 목록에서 그 프롬프트가 보여요”
- 재료: 3단계 Ⅰ 기능 문장 · 3단계 Ⅲ 꼭 · 있으면 좋음 · 4단계 Ⅲ 고른 까닭

## 도는지 보기

> 이어진 게 실제로 도는지 확인하기

- 프롬프트를 하나 넣고 목록을 열어 보면 → 방금 넣은 프롬프트가 목록에 보이면 된다
- 어떻게: 고름 — 플로로가 권한 것: “프롬프트를 하나 넣고 목록을 열어 보면 → 방금 넣은 프롬프트가 목록에 보이면 된다”
- 재료: 3단계 Ⅰ 기능 문장 · 2단계 Ⅲ 한 문장 한 가지

## 작게 나누기

> 남은 일을 작은 할 일로 나누기

- 카테고리로 보기 / 낱말 검색 / 즐겨찾기 / 번호로 메뉴 고르기 화면 / 저장한 내용 파일에 남기기 / 성공 기준 정하기(아직 모름)
- 어떻게: 고름 — 플로로가 권한 것: “카테고리로 보기 / 낱말 검색 / 즐겨찾기 / 번호로 메뉴 고르기 화면 / 저장한 내용 파일에 남기기 / 성공 기준 정하기(아직 모름)”
- 재료: 3단계 Ⅲ 꼭 · 있으면 좋음 · 1단계 Ⅳ 크기 · 2단계 Ⅱ 왜 · 어디까지 · 언제 성공

## 비밀값 검사

> 비밀번호·키 같은 비밀값이 코드와 기록에 남지 않았는지 확인하기

- 키나 비밀번호는 .env 파일에 두고 올리지 않아요(.gitignore에 적기). 올리기 전에 코드에서 키 글자가 없는지 검색해요.
- 어떻게: 고름 — 플로로가 권한 것: “키나 비밀번호는 .env 파일에 두고 올리지 않아요(.gitignore에 적기). 올리기 전에 코드에서 키 글자가 없는지 검색해요.”
