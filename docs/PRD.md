## 처음 말한 것

> 1. 미션 소개 GenAI 기초부터 멀티모달 콘텐츠 제작, 노코드 자동화까지 미션을 수행하면서 어느새 프롬프트가 수십 개씩 쌓였을 것입니다.  텍스트 생성을 위한 정교한 지시문부터 이미지 생성용 키워드, 복잡한 페르소나 설계안까지.  하지만 정작 필요할 때 "그때 그 프롬프트 어디 갔지?" 하며 메모장과 노션, 메신저 창을 뒤적였던 경험 또한 한 번쯤은 있으셨을 겁니다.  매번 복사해서 붙여넣고, 흩어진 기록을 찾느라 정작 중요한 '생성'의 흐름이 끊기고 있다면, 이제는 나만의 프롬프트를 체계적으로 관리할 '집'이 필요한 시점입니다.  이번 미션은 파편화된 프롬프트를 관리하는 것을 넘어, 파이썬(Python)이라는 강력한 언어로 내 머릿속 아이디어를 실제 동작하는 소프트웨어로 구현해내는 데 본질적인 가치가

## 1. 문제와 목표 — 1단계

- **불편** — "그때 그 프롬프트 어디 갔지?" 하며 메모장과 노션, 메신저 창을 뒤적이는 불편을 풀어요.
- **달라지는 것** — 프롬프트를 한곳에 모아 카테고리로 나누고, 검색과 즐겨찾기로 바로 찾을 수 있어요.
- **누가** — 미션을 하면서 프롬프트가 수십 개 쌓인 학습자가 써요.
- **크기** — 크기: 보통 — 번호로 메뉴를 고르는 목록 프로그램은 흔한 방법 하나로 풀려요.

## 2. 아이디어와 범위 — 2단계

- **빈칸 채우기** — 누구: 미션을 하면서 프롬프트가 수십 개 쌓인 학습자 · 불편: "그때 그 프롬프트 어디 갔지?" 하며 메모장, 노션, 메신저 창을 뒤적여요 · 해결: 프롬프트를 한곳에 모으고 카테고리로 나눠요 · 어디까지: 번호로 메뉴를 고르는 목록 프로그램 · 언제 성공: 아직 모름
- **왜 · 어디까지 · 언제 성공** — 왜: 흩어진 프롬프트를 찾느라 만드는 흐름이 끊기지 않게 하려고요 · 어디까지: 모으기, 카테고리, 검색, 즐겨찾기까지 (이번에 안 하는 것: 아직 모름) · 언제 성공: 아직 모름
- **한 문장 한 가지** — 프롬프트를 새로 넣으면, 앱은 목록에 저장한다 / 카테고리를 고르면, 앱은 그 카테고리의 프롬프트만 보여 준다 / 낱말을 검색하면, 앱은 그 낱말이 든 프롬프트를 보여 준다 / 즐겨찾기를 누르면, 앱은 그 프롬프트를 따로 모아 보여 준다
- **남의 정보 · 밖으로** — 남의 정보: 아직 모름 (내가 쓴 프롬프트만 담으면 없음) · 밖으로 나가는 것: 아직 모름 (프로그램 안에서만 쓰면 없음)

## 3. 꼭 필요한 기능 — 3단계

- **기능 문장** — 프롬프트를 새로 넣으면, 앱은 목록에 저장한다 / 카테고리를 고르면, 앱은 그 카테고리의 프롬프트만 보여 준다 / 낱말을 검색하면, 앱은 그 낱말이 든 프롬프트를 보여 준다 / 즐겨찾기를 누르면, 앱은 그 프롬프트를 따로 모아 보여 준다
- **숫자로** — 바로 찾을 수 있어요 → 아직 모름 / 수십 개 쌓여요 → 아직 모름 / 성공의 기준 → 아직 모름
- **꼭 · 있으면 좋음** — 프롬프트 저장: 꼭 / 카테고리로 보기: 꼭 / 낱말 검색: 꼭 / 즐겨찾기: 있으면 좋음
- **나온 곳 잇기** — 기능이 4개라 아직 안 해도 돼요
- **막을 일** — 프롬프트를 저장하면, 앱은 그 내용을 프로그램 밖으로 보내지 않는다

## 4. 만드는 방법 — 4단계

- **후보 찾기** — 파이썬으로 직접 만든 프로그램
- **견주기** — 노션은 쉽지만 내 맘대로 바꾸기 어려워요
- **고른 까닭** — 파이썬 프로그램으로 골랐어요. 아이디어를 직접 동작하게 만들고 싶어서요.
- **약속과 맞대기** — 쓸 도구는 파이썬만 써요
- **보는 사람 · 둘 곳** — 나만 볼 수 있게 내 컴퓨터 안에 둬요

## 5. 뼈대와 할 일 — 5단계

- **끝까지 잇기** — ① 프롬프트 하나를 새로 넣어요 → ② 앱이 목록에 저장해요 → ③ 목록에서 그 프롬프트가 보여요
- **도는지 보기** — 프롬프트를 하나 넣고 목록을 열어 보면 → 방금 넣은 프롬프트가 목록에 보이면 된다
- **작게 나누기** — 카테고리로 보기 / 낱말 검색 / 즐겨찾기 / 번호로 메뉴 고르기 화면 / 저장한 내용 파일에 남기기 / 성공 기준 정하기(아직 모름)
- **비밀값 검사** — 키나 비밀번호는 .env 파일에 두고 올리지 않아요(.gitignore에 적기). 올리기 전에 코드에서 키 글자가 없는지 검색해요.

## 6. 만든 것과 확인 — 6단계

- **확인 먼저** — 프롬프트 저장 — 하나 넣고 목록을 열면 방금 넣은 게 보여야 해요 / 카테고리 보기 — 카테고리를 고르면 그 카테고리 것만 나와야 해요 / 낱말 검색 — 낱말을 넣으면 그 낱말이 든 것만 나와야 해요 / 즐겨찾기 — 누르면 따로 모은 곳에 나와야 해요
- **작은 확인** — 저장: 넣은 글이 목록에 있고 빈 글은 안 들어가요 / 카테고리: 다른 카테고리 글은 안 섞여요 / 검색: 없는 낱말이면 '없어요'라고 알려 줘요 / 즐겨찾기: 다시 누르면 빠져요
- **써 보기** — ① 프롬프트 몇 개를 카테고리를 달아 넣어요 → ② 카테고리를 고르고, 낱말도 검색해요 → ③ 마음에 드는 것에 즐겨찾기를 눌러요 → 결과: '그때 그 프롬프트'를 메모장 없이 바로 찾아요
- **비밀값 검사** — 키나 비밀번호는 .env 파일에 두고 올리지 않아요(.gitignore에 적기). 올리기 전에 코드에서 키 글자가 없는지 검색해요. 저장한 프롬프트 파일도 내 컴퓨터에만 둬요.

## 7. 잰 결과 — 7단계

- **숫자 재기** — 정한 숫자 없음 — 3단계에서 먼저 정하기
- **잰 값 적기** — 무엇: (재고 적기) · 잰 날: (재고 적기)
- **못 잰 것** — 성공의 기준 — 아직 못 함(숫자를 아직 정하지 못했어요)
- **아무나 못 들어오게** — 공개하지 않아요 — 이 컴퓨터에서만

## 8. 배운 것 — 8단계

- **돌아보기** — 잘된 점: 프롬프트 저장, 카테고리, 검색, 즐겨찾기를 하나씩 확인하며 통과했어요 · 아쉬운 점: 성공의 기준 숫자를 끝까지 정하지 못했어요
- **왜 다섯 번** — 왜? 성공 기준을 못 정했나 → 숫자로 말하는 걸 미뤘어요 → 처음에 '아직 모름'으로 넘겼어요 → 몇 번 걸리면 성공인지 생각 안 했어요 → 진짜 까닭: 시작할 때 성공 모습을 숫자로 안 그렸어요
- **아찔했던 일** — 없었어요 — 다음엔 프롬프트에 비밀번호나 남의 정보를 적지 않도록 저장 전에 한 번 훑어볼게요
- **배운 것 남기기** — 다음엔 성공 기준을 숫자로 먼저 정할게요 / 다음엔 작은 부분마다 확인 방법을 먼저 적을게요 / 다음엔 비밀값을 .env에 두고 올리기 전에 검색할게요
- **저장소에 올리기** — 문서와 코드 — 커밋: 프롬프트 보관함 첫 판 완성 (.env와 저장한 프롬프트 파일 같은 비밀값은 올리지 않아요)
